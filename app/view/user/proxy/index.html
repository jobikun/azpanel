绑定到个人账号的 SOCKS5 / HTTP 代理，可在添加云账户时绑定，账户的所有操作都会走绑定的代理。

每行一条代理，自动识别以下格式（未写协议时使用下方“默认协议”）：

  • curl --proxy "http://user:pass@1.2.3.4:8080/" https://ipv4.webshare.io/（完整 curl 命令）
  • http://user:pass@1.2.3.4:8080 或 socks5://user:pass@1.2.3.4:1080
  • user:pass@1.2.3.4:8080
  • 1.2.3.4:8080:user:pass（Webshare 下载列表格式）
  • 1.2.3.4:8080（无鉴权）
默认协议：
label

输入 Webshare API Key（控制台 → API Keys）， 一键导入账户下全部代理（兼容 apidocs.webshare.io，mode=direct，自动翻页）。

Webshare 代理同一端口同时支持 HTTP 与 SOCKS5，按需选择协议即可。若希望代理随 Webshare 动态更新，可在“添加 / 编辑”里把来源设为“第三方 API”，仅填 API Key 保存。
